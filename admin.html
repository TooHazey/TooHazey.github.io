Edit your site

Only the owner of this site's GitHub repo can sign in. Changes are saved straight to GitHub and go live in about a minute.

First time? Create your token (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name it Site editor and pick an expiration.
  3. Under Repository access, choose Only select repositories → .
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

Your token never leaves your browser except to talk to GitHub. It can only touch this one repo. Treat it like a password and don't share it.
